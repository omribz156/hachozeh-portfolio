# Country flags (shared identity assets)

Real country flags from the open-source [flag-icons](https://github.com/lipis/flag-icons) set (MIT), named by ISO 3166-1 alpha-2 (e.g. `il.svg`, `br.svg`; England/Scotland/Wales = `gb-eng`/`gb-sct`/`gb-wls`).

**Not sports-specific** — country identity serves any market that resolves to a nation: national-team sports, politics/elections, world/news, fx/currencies, geography. Kept at the image root, not under `sports/`, on purpose.

Scope: 2026 World Cup nations + Israel (~51). Add more nations by dropping the matching ISO `.svg` here.

Attribution: flag-icons is MIT — preserve attribution if these ship to production.
