This source snapshot preserves the Astro/Preact frontend, Fastify/PostgreSQL
backend, market engine, Seer, Oracle, and their tests. It intentionally has no
production repository history, deployment credentials, market-operation receipts,
historical screenshots, or unreviewed media. Internal document links in source
comments may refer to excluded historical material.

Changes specific to this copy:
- Replace subject-specific imagery with generic project-owned category artwork.
- Retain font and flag licenses and a machine-readable media substitution list.
- Omit provider domain-verification files and old deployment workflows.
- Remove maintainer machine paths/accounts and Render resource identifiers.
- Do not auto-load the maintainer's private environment file.
- Do not auto-restart the local evaluation database or permit the private dev host.
- Configure Sentry organization/project through environment variables.
- Keep source visible without silently granting a project-wide reuse license.

The local setup uses synthetic seed data. Retained operational CLI commands are
examples, not authorization to operate Hachozeh production. Browser screenshot
baselines are intentionally omitted and must be regenerated from synthetic data
for a new local environment.

The verification workflow has no deployment steps, provider secrets, privileged
PR triggers, or production database connection. CodeQL is not enabled here:
eligibility requires a compatible open-source license or a separate entitlement.
Semgrep is used for source scanning in this source-visible candidate.

The public Wimbledon client identifier in its adapter was confirmed in the
provider's unauthenticated schedule HTML on 2026-09-26. It is not a private project
credential. This classification does not grant rights to the provider's data.
