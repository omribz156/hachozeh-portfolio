## Portfolio Substitutions

Celebrity photographs, broadcaster imagery, tennis photographs/composites, themed
event artwork, and team-specific images are replaced with the project's generic
category artwork. The original image files are not distributed. Existing paths
remain so rendering and test fixtures do not acquire broken references.
`MEDIA-REPLACEMENTS.json` lists every substituted file and its replacement source.
The registry's rights notes describe the replacement, not the original image.

Default avatar and share preview imagery use the project's Hachozeh brand tile.
Production/research media, marketing videos/audio, old landing bundles, browser
screenshots, design snapshots, and operational reports are omitted entirely.

No blanket license for third-party names, datasets, APIs, or remote content is
implied. Source adapters demonstrate integration code; users must independently
comply with provider terms before collecting or republishing provider data.
No project-wide open-source reuse license has been granted; see `NOTICE.md`.
